# Kuradal/Duradel slayer task site candidates

Account: Lunar spellbook (no standard-spellbook teleports; tablets/jewellery OK), no dwarf cannon,
melee/ranged only, unattended 130-200 kills (per-task amount noted), avoid Wilderness unless no
other option.

## Frost Dragons (amount 70-120, extend 180-240; req Sailing 87 + Combat 85 (DS1 NOT required); required item: none listed, but antifire protection strongly needed)
Targets: Frost dragon (combat 202) — single NPC type, no separate variants; no higher-Slayer-level alt
Unattended difficulty: hard — icy dragonfire needs continuous antifire uptime (potion doses run out unattended) and access itself is Sailing-87-gated
1. Grimstone Dungeon (main area) — Frost dragon, combat 202; coords 2851,10455,0 (cluster spans roughly x2851-2913,y10449-10473, plane 0); spawns many (cluster of ~19 LocLine pins, respawn 4.2s); multi-combat area (not stated single); safespot yes (melee + short-range dragonfire only, explicitly safespottable per wiki); access: no vendored item teleport to Grimstone — reach by Sailing (boat) to the island (this IS the task's own access requirement) or fairy ring code DLP once the island has been moored at least once; needs: 87 Sailing to access at all, Combat 85 to be assigned; hazards: icy dragonfire (briefly freezes without protection; negate fully with super antifire potion alone, or regular antifire potion + anti-dragon shield), dragon melee up to 16 stab
2. Grimstone Dungeon, task-only west area — same Frost dragon; coords unknown (west of main area, only accessible while on-task); spawns ?; access/hazards same as above
Recommend: SKIP unless the account's Sailing level and antifire potion re-dosing are separately solved — this is the newest, most Sailing-dependent task in the list (single location, no wiki-documented alternative), and unattended dragonfire protection (potion timers) is a known unsuitable pattern per project notes on dragon tasks generally

## Gargoyles (amount 130-200, extend 200-250; req Slayer 75 + Combat 80 + Priest in Peril; required item: rock hammer, or granite hammer equipped, or nothing if "Gargoyle Smasher" unlock (120pts) bought and rock hammer carried)
Targets: Gargoyle (combat 111, base); Marble gargoyle (combat 349, superior — only if "Bigger and Badder" unlock bought, uses ranged + a dangerous entrapping special attack)
Unattended difficulty: easy — basement is task-only, dense, safespottable, non-aggressive-reset routine well documented; main requirement is the rock-hammer finishing mechanic (must be scripted) unless the auto-smash unlock is bought
1. Slayer Tower basement — Gargoyle, combat 111; coords 3427,9943,0 (cluster ~3427-3444,y9928-9948); spawns 12; single/no multicombat; safespot yes; access: Slayer ring teleport "Slayer Tower" -> Slayer Tower ground floor (3421,3537,0), then stairs DOWN to basement; needs: on-task only (Raulyn blocks off-task basement kills) + a rock hammer in inventory (or granite hammer equipped, or Gargoyle Smasher unlock); hazards: gargoyles immune to poison/venom here (irrelevant if melee/no poison weapon), still need the smash-at-9hp mechanic scripted unless auto-smash unlock owned
2. Slayer Tower top floor — Gargoyle, combat 111; coords 3432,3540,2 (cluster ~3432-3446,y3535-3548); spawns 8; single/no multicombat; safespot yes; access: Slayer ring -> ground floor, then stairs UP through 3 floors, past banshees/aberrant spectres/other tower monsters that can lower stats without protection; needs: same rock hammer/unlock requirement as above; hazards: passing through other Slayer Tower monsters climbing up (banshee stat drain etc.) makes this route riskier than the basement for an unattended bot
3. Slayer Tower roof (Grotesque Guardians boss arena) — Dawn (228)/Dusk (248/328 2nd form); coords 1697,4575,unknown; spawns 2 (counts as 1 kill unless Double Trouble unlock bought, which is NOT recommended per wiki — halves effective kill rate); multicombat yes; not safespottable; access: only after a brittle key drop from regular basement/top-floor gargoyles; needs: boss-tier gear/supplies, much higher risk; not suitable for routine unattended task grinding
Recommend: 1 — basement is task-only, denser (12 vs 8 spawns), safespottable, avoids the tower's other dangerous monsters that top-floor access requires walking past; script the rock-hammer smash (or buy Gargoyle Smasher unlock to remove that requirement) — otherwise this is one of the easiest tasks on the list
